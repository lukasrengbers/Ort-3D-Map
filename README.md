# Ortsmodell

Web-App, die einen Kartenausschnitt in Niedersachsen in ein mehrfarbig druckbares 3D-Modell (3MF) umwandelt – mit echten Dachformen aus dem amtlichen LoD2-Gebäudemodell.

**App öffnen:** https://DEIN-NAME.github.io/ortsmodell

## Datenquellen

- **Gebäude:** 3D-Gebäudemodell LoD2 © Landesamt für Geoinformation und Landesvermessung Niedersachsen (LGLN), Lizenz [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Straßen, Wasser, Grünflächen, Ortssuche, Kartenhintergrund:** © [OpenStreetMap-Mitwirkende](https://www.openstreetmap.org/copyright), Lizenz [ODbL](https://opendatacommons.org/licenses/odbl/)

Modelle, die mit dieser App erzeugt werden, enthalten Daten aus beiden Quellen. Bei Weitergabe oder Veröffentlichung sind diese Quellen zu nennen.
